## Scientific positioning

This is an original research-software paper for SoftwareX. A package version
number does not make it a journal 'Software Update'. It evaluates the search
cost of an integration of established tools. It makes no claim of a new
inverse-Laplace theory, logarithmic computational complexity, universal
superiority, or physically validated fluorescence components.

The earlier SciPy envelope is no longer the abstract's headline. The primary
control uses one compiled wrapper, compiler, optimizer, and selection machinery.
The linear control is faster on the close pair; both coordinate detectors have
the same aggregate count recovery on the harder sweep.

The 480 cases are reused validation/regression data. The new 960-signal sweep
was specified before outcomes were inspected and prompted no numerical-core
tuning. Log wavelets recover 708 counts, variable projection 737; joint count
and accuracy totals are 573 and 613. All difficult outcomes are retained.
Matrix pencil is scored only on originally uniform samples, with explicit
denominators. Correct counts can conceal extreme rate errors.

Cramer--Rao diagnostics concern local unbiased known-count estimation, with
amplitudes as nuisance parameters. Known-count empirical RMSE and bias include
all twenty realizations per cell. One error or a selected-model estimate is
not certified by this bound.

The measured source is Kupfer et al., Zenodo v3, DOI 10.5281/zenodo.20792957,
CC BY 4.0. Original files and attribution are retained. Gate and background
rules were fixed before fitting. Counts vary with gating and variable projection
has lower residuals. IRF convolution, photon-likelihood fitting, and independent
lifetime truth remain outside this demonstration.

## Reproduction

The study requires NumPy, SciPy, Matplotlib, pybind11, a compiler, and LaplaceX.
Commands are in `../benchmarks/research/REPORT.md`. Native measurements and checks
were performed on Windows. Do not replace the installed package extension with
the external benchmark harness.

Regenerate manuscript assets without numerical experiments:

```powershell
.venv\Scripts\python manuscript\prepare_evidence.py
.venv\Scripts\python manuscript\render_markdown.py
```

Compile `main.tex` with Tectonic or LaTeX/BibTeX from `manuscript/`.
